# 品类基线（Category Priors）

用户一句话往往已经说出了品类、体积、来历、状态。**先抽尽信息，只对真正的缺口发问**，这是采集效率的关键。

## 1. 一句话能抽出哪些维度

| 话里的线索 | 直接能定的维度 | 例子 |
|---|---|---|
| 品类名词 | 空间友好度 + 替代难度 | "手机盒"→小、不值钱；"钢琴"→大件、贵重 |
| 时间词 | 使用频率 | "上周刚用"→5；"去年夏天"→2；"好几年没碰"→1；"买来没用过"→0 |
| 来源词 | 情感价值 | "我妈织的"→5；"旅游带回来的"→4；"公司发的"→1 |
| 状态词 | 功能状态 | "还能用"→4；"有点旧"→3；"坏了/过期"→0 |
| 数量词 | 替代难度 | "家里还有三个"→0 |
| 位置词 | 空间友好度 | "塞在抽屉里"→4；"占了半个阳台"→0 |
| 用途词 | 未来需求 | "留着保修用"→4；"没想好，万一"→2 |

**示例**：用户说"一个手机盒"——一句话就定下了四个维度：

- 空间友好度 5（一个小盒，还能压扁）
- 使用频率 0（盒子本身没有使用场景）
- 替代难度 1（随手机附送，无独立价值）
- 功能状态 4（完好，只是个包装）

真正需要问的只剩两句：**"你留着它是为了保修、退换，还是准备转卖手机？"**——答"为了保修/转卖"则未来需求 4，结论可能转为保留；答"没什么，就是没扔"则未来需求 0，直接建议丢弃/回收。

## 2. 使用方式

1. 听用户描述，抽取上表中的线索，能定的维度直接定。
2. 识别品类，未定的维度按基线填，报告中标记为**推断**。
3. 只对基线里"需确认"列出的维度发问——通常只有一两项。
4. 展示时说明哪些是推断值，用户纠正事实即可改分。

命令行与脚本对应：`assess_item.py --category <key>`，或 JSON 里给物品加 `category` 字段；`--list-categories` 查看全部基线。

## 3. 基线数值

**数值以 SKILL.md「品类基线速查表」为准**，此处不重复，避免两处漂移（`calibrate.py` 会校验两处是否一致）。下面是各品类的关键特征与判读要点：

| 品类 | key | 关键特征 | 需确认 |
|------|-----|----------|--------|
| 手机 / 数码包装盒 | `phone_box` | 无使用场景、随手可得 | 未来、情感 |
| 线材 / 充电线 | `cable` | 最易囤积，只留当前设备用的 | 使用、功能 |
| 一年以上没穿的衣服 | `clothing` | 合身与情感是变量 | 情感、功能 |
| 未读 / 读完的书 | `book` | 可转赠或数字化 | 情感、未来 |
| 说明书 / 保修卡 | `manual` | 可拍照存档，跟物件走 | 未来 |
| 包装袋 / 纸箱 | `packaging` | 留少量常用尺寸 | 使用 |
| 厨具 / 餐具 | `kitchenware` | 功能重复是重点 | 使用 |
| 小家电 | `appliance` | 一年没通电多半不再需要 | 使用、功能 |
| 兴趣装备 | `hobby` | 看兴趣还在不在 | 使用、未来 |
| 别人送的摆件 | `gift` | 情感几乎是唯一变量 | 情感 |
| 孩子成长纪念物 | `kids` | 可数字化后精简 | 情感 |
| 亲人的遗物 | `keepsake` | 情感 5，不会判丢弃 | 无需 |
| 旧手机 / 旧电脑 | `device` | 先备份并清除数据 | 功能、未来 |
| 家具 / 大件 | `furniture` | 空间权重最高 | 功能、使用 |
| 证件 / 合同 | `document` | 硬规则强制保留 | 无需 |
| 过期食品 / 药品 | `expired` | 硬规则立即处理 | 无需 |

## 4. 注意

- 基线是**起点，不是结论**：用户给了分数一律以用户为准，基线只填空。
- 推断值必须在报告里标注，用户随时可改。
- 品类没命中基线表时，不要硬套；回到 `evaluation-workflow.md` 1.1 的口语提问逐项补。
- 高 emotional 品类（遗物、成长纪念物）的情感分取上限，宁可高估也不低估。
- "家长说留着以后有用"是他人意见，**不计入未来需求**；一年级课本、旧作业本这类按 `book` 基线处理，情感取 1–2（微乎其微但确实有一点），结论通常落在建议流转或暂存观察。
- 情感价值 1–2 且无使用场景的物品（如一年级的书），用户多半会在结论出来后反悔——按 `evaluation-workflow.md` 第 7 节的摇摆话术处理，不要因此改分数。
