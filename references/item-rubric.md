# 物品去留评分标准（Item Rubric）

统一口径：**所有维度 0–5 分，分数越高越倾向保留。**

## D1 使用频率 usage（默认权重 0.25）

口语问法：**上一次真正用到它，是什么时候？**（答案→分数映射见 `evaluation-workflow.md` 1.1）

| 分 | 判定 |
|----|------|
| 5 | 每周多次或每天都在用 |
| 4 | 每月数次 |
| 3 | 一年 3–11 次 |
| 2 | 一年 1–2 次 |
| 1 | 过去一年没用过，但以前常用 |
| 0 | 入手后从未使用过 |

要点：以"实际拿起来用过"为准，看见过、挪动过不算使用。

## D2 未来需求 future（默认权重 0.20）

口语问法：**接下来一年，有没有具体哪件事会用到它？**

| 分 | 判定 |
|----|------|
| 5 | 已排上日程，近期必用（已预约、已计划） |
| 4 | 明确会用到（季节性/周期性，如年节用品） |
| 3 | 可能用到，能说出具体场景 |
| 2 | 说不清，只是"万一用得上" |
| 1 | 想不出任何使用场景 |
| 0 | 生活方式已改变，确定不会再需要 |

要点："万一"不是需求，只值 2 分。季节性物品按 4 分处理，但要确认该季节确实还会过。

## D3 功能状态 condition（默认权重 0.15）

口语问法：**现在还能用吗？**

| 分 | 判定 |
|----|------|
| 5 | 全新或接近全新，功能完好 |
| 4 | 有正常使用痕迹，功能完好 |
| 3 | 可用，有轻微损耗或需小修（换电池、补配件） |
| 2 | 需较大维修才能使用 |
| 1 | 勉强可用，明显老化 |
| 0 | 损坏不可修复 / 变质 / 过期失效 |

要点：0 分会触发硬规则——不可修复件直接建议处理，除非情感价值 ≥ 4。

## D4 替代难度 replace（默认权重 0.15）

口语问法：**如果现在需要，还能再弄到一个吗？**（问重新获得，不问当初花销）

| 分 | 判定 |
|----|------|
| 5 | 无法再获得（绝版、唯一、定制、亲手制作） |
| 4 | 很难获得或很贵（需专门寻找、花费显著） |
| 3 | 可买到，但需专门跑一趟或中等花费 |
| 2 | 容易网购，价格可接受 |
| 1 | 随处可得，很便宜 |
| 0 | 免费可得，或家里已有多个同类 |

要点：只算"重新获得成本"，不算当初花了多少钱。贵但随手能买的，仍是 1–2 分。

**两个偏差会污染这一维**：

- **沉没成本**：用户说"当年买成三千"——那笔钱已经花完，与现在能否再弄到无关，不计分。
- **禀赋效应**：用户说"这个挺值钱的"——一旦拥有就会高估价值（愿意卖的价远高于愿意买的价）。用 **WTP 检验**反问：「如果它现在不在你家，**今天**你愿意掏钱再买一个吗？愿意出多少？」用买价替换卖价，并直接按金额换算本维度分数。

**WTP 检验**（willingness to pay）是本维度的实测法，比定性描述更可靠：

| 回答 | 处理 |
|---|---|
| 说出具体金额 | 用 `--price <金额> --economy <档位>` 换算，或填 `wtp` 字段，脚本自动改写替代难度 |
| 说不出数字 / "看情况" / "以后再说" | 按**不会买**：替代难度 ≤ 2（通常记 1） |
| "一分钱都不想花" | 替代难度记 1 |
| "买不到了，出多少都买不着" | 定性优先，记 5，与金额无关 |

"今天"两个字不能省——"总有一天会买"等于不会买。

**经济档位校准**：本维度的价格阈值随用户经济状况缩放（预算敏感 / 常规 / 预算宽裕三档，见 `evaluation-workflow.md` 第 8 节）。同一个"两百块"，预算敏感者记 4 分，宽裕者记 2 分。定性判断（买不到 / 家里有好几个）不受档位影响。

## D5 情感价值 sentiment（默认权重 0.15）

口语问法：**它是从哪来的？**（问来源，不问强度）

| 分 | 判定 |
|----|------|
| 5 | 与重要的人或时刻绑定，无可替代 |
| 4 | 明确带来愉悦或安心，有具体回忆 |
| 3 | 有些喜欢，丢掉会有点可惜 |
| 2 | 轻微好感 |
| 1 | 基本无感，只是"一直没处理" |
| 0 | 看到就烦躁，或关联负面记忆 |

要点：5 分触发硬规则——结论最低为「暂存观察」，绝不输出"丢弃"。愧疚感（"花了不少钱"）不是情感价值，计入 1 分。

## D6 空间友好度 space（默认权重 0.10）

口语问法：**它现在放在哪儿，占多大地方？**

| 分 | 判定 |
|----|------|
| 5 | 收纳后几乎不占空间（可叠放、可数字化） |
| 4 | 占一个小格 |
| 3 | 占一格层板或一个抽屉 |
| 2 | 占半个柜子 |
| 1 | 占一整柜或算大件 |
| 0 | 占据独立区域/房间，明显挤压生活动线 |

要点：这是"越不占地方分越高"的反向维度，打分时务必确认方向。

## 常见品类速判基准

> 完整的品类基线（六维默认值、需确认项、品类提示）见 `category-priors.md`，下表仅为快速参照。

| 品类 | 常见得分形态 | 一般走向 |
|------|--------------|----------|
| 超过一年未穿的衣物 | usage 1–2、condition 3–4、replace 1–2 | 建议流转 |
| 未读且无计划的书 | usage 0–1、future 2、space 4 | 建议流转 |
| 旧数码产品（可用） | usage 0–1、condition 3–4、replace 3 | 暂存观察 → 转卖 |
| 过期药品/化妆品 | condition 0 + expired | 立即处理 |
| 证件/合同/产权文件 | document 标记 | 强制保留 |
| 亲人遗物 | sentiment 4–5 | 封存或纪念化 |
| 重复功能的厨具 | usage 2、replace 0 | 建议流转 |
| 孩子的成长纪念品 | sentiment 4–5、usage 0 | 封存（数字化后精简） |

## 打分自检

1. 每个分数能否对应一句可复述的事实？不能则说明在猜，取低一档。
2. 六个维度是否都被反向维度（空间友好度）搞混了方向？
3. 是否把"当初很贵"（沉没成本）或"它挺值钱"（禀赋效应）误算进了情感价值或替代难度？
4. 命中硬规则的物品是否已直接标注 flag，而不是靠分数表达？
